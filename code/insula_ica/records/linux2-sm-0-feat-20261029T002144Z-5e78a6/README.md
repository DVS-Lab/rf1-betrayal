Same recorded fMRIPrep BOLD, task EVs and saved TEDANA+nuisance matrix; only FEAT smoothing changes from 5 mm to 0 mm, with new output locations. No original wrapper, fMRIPrep, TEDANA or Warpkit was executed. No existing sm-5 fit was overwritten. All sm-0 filtered data, native residuals, autocorrelations and PEs are retained. Worker queue slots: 64, with 1 GiB reservations and 8 GiB headroom. See input-plan.json for exact saved BOLD paths and missing inputs. Available inputs are processed independently; missing pre-smoothing BOLD is never replaced with already-smoothed filtered_func_data. This record prepares the separate FEAT stream; registration/coverage and ICA review remain separate.
