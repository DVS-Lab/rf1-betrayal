All 132 manuscript participants and 490 accepted runs are included. The 3- and 7-component task fits use existing fixed ICA maps; the completed pooled 5-component results are reused unchanged (see reused-five-component-verification.json). The insula mean is the actual masked input-BOLD average, fitted as a separate response.

Each series has five bars: pooled nonsocial/social UGR fairness slopes and computer/friend/stranger Trust reciprocate-minus-defect contrasts.
