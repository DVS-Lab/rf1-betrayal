# Pooled high/low task model: review of all five components

All 249 UGR runs completed the common-slope model; 241 Trust runs were reused unchanged. All 132 participants and 490 accepted runs were retained. No numerical or publication errors were recorded.

## Pooling resolves the unstable fit in the new model

Sub-11031 UGR run 1 has standardized nonconstant-design condition number 60.3624 after pooling, versus 19,935,762 in the original separate-slope model. The largest condition number across the 249 pooled UGR designs is 166.235. All run-level effects are finite and below absolute 0.428 across the combined task tables.

This identifies a common social high/low slope, with fairness information in this case supplied by social-low variation. It does not identify a separate social-high slope from three identical event amplitudes. The four high/low condition main effects, RT/missed-trial EVs and all nuisance columns remain in the model. Original FEAT and paper group results were not edited.
