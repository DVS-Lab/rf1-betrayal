Network task analysis uses stage-1 spatial-regression timecourses from task-preserved, 4D input to FEAT, then joint OLS with z-scored responses and every column of the complete saved task+nuisance design. Five bars per component: UGR nonsocial/social pmods averaged over high/low; Trust C/F/S reciprocate minus defect. No connectivity, randomise, ICA, fMRIPrep, FEAT preprocessing, FILM, nuisance filtering or PPI is run. See ../2026-10-29-network-timecourse-methods/README.md for methods.
